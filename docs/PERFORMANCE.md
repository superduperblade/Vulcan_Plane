# Performance

Benchmarks, bottlenecks, target hardware, performance constraints, major
optimizations, and known performance limitations.

## Measurement Environment Warning

This development container has no GPU. Vulkan runs on **lavapipe
(llvmpipe, software rasterizer)**. CPU-side timings (generation, streaming,
allocation, frame-loop CPU cost) measured here ARE meaningful. GPU timings
measured here are NOT representative of real hardware and must not be
recorded as performance results. GPU/VRAM numbers must come from the target
hardware.
